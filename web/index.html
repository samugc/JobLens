Limitations and method

This is a synthetic portfolio demo. It is not an ATS, a hiring predictor or a substitute for reading the posting. The evaluator uses a deliberately narrow skill vocabulary; anything it does not recognise remains for manual review.

    The private project also contains an optional local Ollama tool-calling agent. It is not part of this public snapshot, and this demo makes no LangGraph claim.
